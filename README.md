# Pro

Репозиторий подготовлен как основа для будущего проекта в облачном Codex. Исходники приложения пока не загружены.

## Базовая проверка

```bash
bash scripts/cloud-setup.sh
```

Скрипт проверяет рабочую директорию Git и показывает доступные инструменты. Зависимости приложения пока не устанавливаются: стек ещё не определён.

## Настройка облачного окружения

- Репозиторий: n2np9fc5zy-create/Pro, ветка main.
- Команда скрипта установки: bash scripts/cloud-setup.sh
- Инструкции для агента: AGENTS.md в корне репозитория.
- Секреты и переменные задаются в настройках окружения, не в Git.
- После изменения настройки окружение необходимо сохранить и опубликовать через интерфейс Codex.

## Загрузка проекта

Добавьте исходники в корень репозитория, сохранив инструкции AGENTS.md. Если у проекта уже есть одноимённые файлы, объедините их содержимое. Включите README, манифесты, lock-файлы и пример конфигурации без секретов.

Затем поручите Codex: «Изучи проект, адаптируй scripts/cloud-setup.sh под его зависимости, выполни установку, тесты и сборку и исправь проблемы облачного запуска».

До загрузки исходников команды запуска приложения, сборки и тестов не определены. Базовый скрипт не доказывает работоспособность будущего приложения.
