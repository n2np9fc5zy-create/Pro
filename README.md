# Pro — Hornet AI

В `hornet/` перенесён прототип из архива `hornet_ai_starter.zip`, созданного в чате про Hornet. Он содержит веб-панель, SQLite и генерацию ответов. Подключения к аккаунту Hornet и отправки сообщений в нём пока нет.

## Облачный Codex

Окружение Pro связано с этим репозиторием. Скрипт установки уже задан: `bash scripts/cloud-setup.sh`. Он устанавливает зависимости Python в `.venv` из `hornet/requirements.lock`.

Запуск панели:

```bash
bash scripts/run-hornet.sh
```

Адрес внутри среды: http://127.0.0.1:8000. Сервер слушает локальный интерфейс. История хранится в `.local/hornet/chats.db` и исключена из Git. Облачная среда разработки не заменяет постоянный VPS для работы 24/7.

Без `OPENAI_API_KEY` работают явно помеченные демонстрационные ответы. Ключ задаётся через секреты окружения; модель — через `OPENAI_MODEL`. Файл `.env` при запуске скриптом автоматически не читается. Настройки `AUTOPILOT`, `DB_PATH` и `PORT` можно передать через окружение.

Для VPS и Docker см. [исходную инструкцию](hornet/README.md).

## Проверка без API и Hornet

```bash
.venv/bin/python tests/smoke_hornet.py
```

Проверка использует временную БД и вымышленные сообщения. Проверяет создание двух диалогов, раздельную историю, генерацию демо-ответа, защиту от повторной генерации без нового сообщения и удаление диалога.
