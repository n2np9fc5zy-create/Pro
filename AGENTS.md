# Инструкции для Codex

- Общайся с пользователем по-русски.
- Проект Hornet AI находится в hornet/: Python, FastAPI, SQLite, веб-панель. Это демонстрационный движок, подключение к Hornet ещё не реализовано.
- После загрузки проекта сначала изучи его README, инструкции AGENTS.md в подпапках, манифесты и lock-файлы. Сохраняй существующую архитектуру.
- Выполняй задачи до проверяемого результата. Самостоятельно решай обычные обратимые технические вопросы; уточняй только существенные недостающие требования.
- Вноси небольшие изменения по задаче. Не перезаписывай чужие незакоммиченные изменения.
- Устанавливай зависимости по lock-файлам средствами выбранного проектом менеджера. Не смешивай менеджеры и не обновляй версии без необходимости.
- Запускай относящиеся к изменению проверки, тесты и сборку. Установка: bash scripts/cloud-setup.sh. Проверка: .venv/bin/python tests/smoke_hornet.py. Запуск: bash scripts/run-hornet.sh. Не подключай реальные аккаунты и не отправляй сообщения при проверках.
- Секреты храни в настройках окружения. Не коммить .env, ключи, токены, личные документы и реальные пользовательские данные; для примеров используй вымышленные данные.
- В итоговом ответе кратко укажи: что изменено, что проверено, какие ограничения остались. Не называй настройку облака или запуск успешными без проверки.
