# 🦆 Hornet AI — стартовый прототип

**Версия:** 0.1.0. **Только демонстрационный режим**: проект не получает и не отправляет сообщения через Hornet. Подключение к Hornet требует разрешения платформы. Не содержит скрытой автоматизации, scraping, обратного инжиниринга и обхода защиты.

## Что работает

- Постоянная работа на VPS в Docker.
- Веб-интерфейс для симуляции входящих сообщений и генерации ответов.
- Генерация русскоязычных остроумных ответов через OpenAI API (если задан ключ).
- Хранение истории по каждому отдельному диалогу в SQLite.
- Настраиваемый режим `AUTOPILOT=true`: после добавления входящего сообщения *локально генерирует* ответ, но **никуда его не отправляет**.
- Удаление истории конкретного диалога.
- Без API-ключа — специально помеченные демонстрационные ответы вместо настоящего ИИ.

## Запуск на Ubuntu VPS

Тебе потребуется свой VPS, установленный Docker Engine и Docker Compose Plugin.

1. Перенеси каталог проекта на VPS, например в `~/hornet-ai`.
2. `cd ~/hornet-ai`
3. `cp .env.example .env`
4. `nano .env` — запиши `OPENAI_API_KEY=...` и, если нужно, `AUTOPILOT=true`. Не выкладывай `.env` и ключ в чат или GitHub.
5. `docker compose up -d --build`
6. На своём Windows PC открой PowerShell и создай защищённый туннель: `ssh -L 8000:127.0.0.1:8000 USER@SERVER_IP`.
7. Открой браузер на **своём компьютере**: `http://127.0.0.1:8000`.

Контейнер намеренно слушает только локальный интерфейс сервера; напрямую через IP панели не видно. Пароль SSH/приватный ключ защищает туннель. Не пробрасывай порт 8000 на публичный интерфейс без полноценной авторизации и HTTPS.

**Работа без Docker** (тест локально): `pip install -r requirements.txt`; затем в PowerShell задаётся переменная `DB_PATH` с абсолютным путём, а сервер запускается командой `uvicorn app.main:app --port 8000`. Если хочешь OpenAI, выставь `OPENAI_API_KEY` в окружении. `.env` автоматически вне Docker не загружается.

## Протестировать

- В интерфейсе создай диалог `Дима`.
- Добавь входящее сообщение `Привет. Я встречаюсь за МП. Тебе интересно?`.
- Нажми **Сгенерировать ответ**. При `AUTOPILOT=true` ответ сформируется сразу при добавлении входящего.
- Повтори для другого диалога. Контекст не смешивается.
- Ни одно сообщение при этом в Hornet не попадает.

## Для следующего этапа

Добавить интерфейс провайдера с методами `receive()`, `send()`, `ack()` **только при наличии официально разрешённого способа подключения**. Настроить проверку подлинности входящих, шифрование данных, ограничения частоты, запрет нежелательных повторных сообщений, подтверждение перед действиями в реальной жизни и предельное время хранения переписок.

## Безопасность и ограничения

- Переписки могут содержать крайне личные данные. Обращайся с ними как с конфиденциальными. Сообщения отправляются на OpenAI API при включённом ключе; оцени законные основания и согласие на обработку чужих данных.
- Не заполняй здесь настоящие чужие переписки без согласия участников.
- Избегай несанкционированной отправки, спама и выдачи себя за другого человека; обозначай использование ИИ для собеседников.
- Не отправляй данные доступа Hornet или OpenAI в сообщения чата.
- SQLite сохраняется в `./data`; установи права на каталог и резервные копии только с шифрованием.
- Пока это **демонстрация технического движка**, а не настоящий автономный бот Hornet.

## Как отключить

`docker compose down` останавливает сервер. Каталог `data` остаётся, а `docker compose up -d` запускает заново.
